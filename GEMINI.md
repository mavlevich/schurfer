# Pull Request Descriptions

When asked to generate or write a description for a Pull Request (PR):

- **ALWAYS** write the description entirely in English, regardless of the language used in the conversation.
- **ALWAYS** output the description in raw Markdown format.
- **ALWAYS** follow Best Practices for PR descriptions (e.g., use Conventional Commits style titles, include a clear summary of changes, outline the impact/rationale, and note any testing or verification steps).
