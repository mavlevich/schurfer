## Blocking findings

### C-F4 — P1: old instrument terminates a cursor catalog with pages remaining

Location: `apps/analytics/schurfer_analytics/catalyst_feasibility.py:256–257,423–428`.

`cut_page()` sets `oldest_reached` from `launchTime` for instruments as well as
announcements. `_one()` treats it as terminal even with a nonempty
`nextPageCursor`. A still-trading instrument launched before February 2023 can
therefore end enumeration before later pages containing eligible instruments.
A catalog is not a reverse-chronological announcement feed. The official
[Bybit API contract](https://bybit-exchange.github.io/docs/v5/market/instrument)
prescribes following the cursor and supplies no launch-time sort guarantee.

Synthetic reproduction: first response contains one pre-2023 instrument and
`nextPageCursor="page2"`; second contains an eligible instrument. Observed:
only the first request is made, `complete=true`. Missing instruments become
`no_live_perp`, biasing bucket counts and potentially causing a false stop.

Fix direction: separate catalog exhaustion from announcement time boundaries;
for instruments follow cursors to exhaustion within the declared budget. Add a
regression test where an old instrument occurs before a newer one on another page.

### C-F5 — P1: page budget exhaustion is labelled complete history

Location: `apps/analytics/schurfer_analytics/catalyst_feasibility.py:423–428,456–471,953–955`.

Reaching `MAX_PAGES_PER_SERIES` sets `terminal=true`, just like reaching the end
of history. `summary()` then permits the formal report. A busy announcement
catalog may consume the cap before either research window is covered. Its missing
events can be reported as `insufficient_events` rather than unknown coverage.

Synthetic reproduction: lower the cap to one page and return a nonempty page
newer than the research cut. Observed: `complete=true` despite never reaching
either window. This exercises the same condition as page 600 in production.

Fix direction: distinguish `exhausted`, `time_boundary_reached` and
`budget_exhausted`; the last must not produce a complete formal report. Preserve
the global budget. A limit is not evidence that the source has no more events.
