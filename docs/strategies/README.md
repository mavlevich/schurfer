# Trading strategies

Each strategy is a single markdown file.

## Strategy lifecycle

1. **draft** - idea, informal description (current level of pump_short_v1)
2. **paper** - formalized, traded in paper mode
3. **shadow** - paper alongside real markets, logged but not executed live
4. **live_micro** - live trading with minimal position sizes
5. **live** - full size
6. **deprecated** - disabled

## Naming

`{strategy_type}_v{N}.md` - pump_short_v1, funding_arb_v1, etc.
Major rule changes bump the version (v2).

## Format

See `pump_short_v1.md` as an example.
